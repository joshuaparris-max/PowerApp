# PowerApp

PowerApp is a private, safety-first educational guide and conversation tool for adult couples. Its purpose is to facilitate healthy communication, consent, emotional safety, and aftercare.

## 🛡️ Safety & Purpose
- **Educational Only**: This app is not a substitute for professional counseling, medical advice, or crisis support.
- **Consent Focused**: Built around the principles of SSC (Safe, Sane, Consensual) and the 4Cs.
- **Non-Explicit**: The app contains no graphic content or instructions. It is a relationship-safety tool.
- **Stop is Success**: Validates that pausing or stopping at any time is a positive outcome of the safety system.

## 🔒 Privacy Model
- **Local-Only Storage**: All data (notes, worksheet responses, plans) stays strictly in your browser's `localStorage`.
- **No Servers**: No data is ever sent to a server. We have no access to your information.
- **No Tracking**: No analytics or tracking scripts are used.
- **Panic Clear**: Includes a one-tap button to instantly delete all saved data from the device.

## 🛠️ Setup & Development
1. Clone the repository.
2. Install dependencies: `npm install`
3. Start development server: `npm run dev`
4. Build for production: `npm run build`
5. Format code: `npm run format`
